# Как вести сайт самому

Короткая шпаргалка: как добавить запись в блог, как выложить новую версию мода
и что делать, если что-то сломалось. Программировать не нужно — везде правится
только текст в готовых шаблонах.

---

## 1. Новая запись в блоге

Открой **`assets/data/posts.js`** в любом текстовом редакторе (Блокнот тоже
подойдёт, но лучше VS Code или Notepad++ — они подсвечивают ошибки).

Найди строку `window.BLOG_POSTS = [` и вставь **сразу после неё** новый блок:

```js
  {
    date:  '2026-09-14',
    title: 'Заголовок записи',
    mood:  'настроение',
    music: 'Исполнитель — Трек',
    body: [
      'Первый абзац.',
      'Второй абзац.'
    ]
  },
```

Записи идут сверху вниз, поэтому **новая всегда добавляется первой**. Не забудь
запятую после закрывающей `}` — она отделяет запись от следующей.

### Что в полях

| Поле | Обязательное | Что писать |
|---|---|---|
| `date` | да | Дата в формате `ГГГГ-ММ-ДД`. На странице сама превратится в «Понедельник, 14 сентября 2026» |
| `title` | да | Заголовок. Появится в синей полоске |
| `mood` | нет | Настроение. Жёлтая полоска «Current mood:». Не нужно — удали строку целиком |
| `music` | нет | Что слушаешь. Там же, рядом с настроением |
| `body` | да | Список абзацев. Каждая строка в кавычках — отдельный абзац |

### Абзацы

Каждый абзац — отдельная строка в кавычках, через запятую:

```js
    body: [
      'Первый абзац.',
      'Второй абзац.',
      'Третий абзац.'
    ]
```

После **последнего** абзаца запятая не нужна.

Длинный абзац можно разбить на несколько строк через `+`, чтобы не тянуть его
за край экрана — на странице он всё равно останется одним абзацем:

```js
      'Очень длинный абзац, который не влезает в одну строку, ' +
      'поэтому продолжается здесь и склеивается в один текст.',
```

Обрати внимание на **пробел перед закрывающей кавычкой** — иначе слова слипнутся.

### Ссылки

Внутри абзаца ссылка пишется в квадратных скобках, адрес — в круглых:

```js
      'Скачать можно [на главной](index.html) или [на Modrinth](https://modrinth.com).'
```

Внешние ссылки сами открываются в новой вкладке. HTML-теги внутри текста
**не работают** — это защита от случайно сломанной вёрстки, любой `<div>` просто
покажется как текст.

### Кавычки и апострофы

Текст записи стоит в одинарных кавычках `'...'`. Если внутри текста нужен
апостроф, поставь перед ним обратный слэш:

```js
      'Это Hen\'s blog',
```

Проще — использовать кавычки-ёлочки «...» или двойные `"` внутри текста, с ними
ничего экранировать не нужно.

## 2. CD Player

Поле **Track** в окне плеера — поисковое. Начинаешь печатать название, снизу
выпадает список найденных треков с обложками; выбираешь мышкой или стрелками
↑ ↓ и Enter. Исполнитель и обложка подставляются сами, выбор запоминается в
браузере и остаётся после перезагрузки.

Ищет через **iTunes Search API** — он бесплатный, не требует ключа и разрешает
запросы прямо из браузера. Genius так не умеет: нужен токен, который на
статическом сайте лежал бы открытым, и запросы со сторонних страниц он не
принимает — поэтому для разборов и понадобился воркер.

Что это значит на практике: пока никто не печатает в этом поле, страница никуда
не ходит. Как только начал печатать — запрос уходит на серверы Apple, и обложка
грузится оттуда же. Это единственное место на всём сайте, которое обращается
наружу.

Работает и на сайте, и при открытии `blog.html` двойным кликом с диска: если
обычный запрос заблокирован (а из файла браузер его всегда блокирует), поиск
сам переключается на запасной способ.

Кнопки внизу плеера (перемотка, play, стоп, запись) нажимаются и двигают
ползунок, но музыку не играют — звука на странице нет вообще.

### Окно lyrics.txt

После выбора трека само открывается окно с альбомом, годом, жанром,
длительностью и ссылками «читать текст» на Genius и Apple Music.

В это окно можно добавить **описание песни и разборы строк** с Genius: что
значит строчка, откуда отсылка, как записывали. Как включить —
[worker/README.md](worker/README.md), минут двадцать, бесплатно. Пока не
включено, окно показывает ссылки.

Самого текста песни там не будет ни при какой настройке: Genius не отдаёт тексты
через API вообще — у них договоры с издателями. Поэтому окно даёт ссылку туда,
где текст опубликован законно.

Свои заметки к треку можно добавить в `assets/data/posts.js`:

```js
window.BLOG_TRACK_NOTES = {
  'Kai Angel — andy warhol': ['Первое, что я у него услышал.', 'До сих пор лучший.']
};
```

Ключ — `'Исполнитель — Трек'` ровно так, как их показывает поиск (регистр не
важен). Значение — строка или список абзацев. Это место для твоего текста:
мыслей о песне, перевода, своих стихов.

Значение по умолчанию (что показано, пока посетитель ничего не выбрал) задаётся
в `assets/data/posts.js`, в самом верху:

```js
window.BLOG_NOW_PLAYING = 'Исполнитель — Трек';
```

Пустые кавычки — плеер просто ничего не покажет. Разделитель между исполнителем
и треком — тире или дефис, любой.

## 3. Новая версия мода

Файл **`assets/data/versions.js`**.

1. Собери мод и положи оба jar-ника в `assets/downloads/`.
2. Добавь блок **в начало** списка `window.LIDAR_VERSIONS = [`:

```js
  {
    version:   '1.1.0',
    date:      '2026-10-01',
    minecraft: '26.2',
    loader:    '0.19.3+',
    fabricApi: '0.156.0+26.2',
    java:      '25',
    size:      '32 KB',
    jar:       'assets/downloads/lidar-scanner-1.1.0.jar',
    sources:   'assets/downloads/lidar-scanner-1.1.0-sources.jar',
    summary:   'Одно предложение о том, что это за сборка.',
    changes: [
      'Что изменилось',
      'Ещё что-то'
    ]
  },
```

Дальше всё само: на странице версий появится карточка, прошлая версия
автоматически станет «Legacy», а на главной обновятся номер версии, версия
Minecraft, размер, ссылки на скачивание и имя jar в инструкции по установке.
Руками в HTML лезть не нужно.

Если sources-jar нет — напиши `sources: null`, лишняя кнопка не появится.

## 4. Как посмотреть, что получилось

Просто **открой `blog.html` двойным кликом** — сайт работает и без сервера,
прямо из файла. То же с `index.html` и `versions.html`.

Если правки не видны — браузер показывает страницу из кэша. Жми **Ctrl + F5**
(жёсткая перезагрузка).

## 5. Публикация

Сайт лежит в git и раздаётся на `www.heppa.online`. Когда всё устраивает:

```bash
git add -A
git commit -m "новая запись в блоге"
git push
```

После пуша страница обновляется в течение пары минут.

## 6. Если сайт сломался

Симптом почти всегда один: **блог открылся, а записи пропали** (или на странице
версий пусто). Это значит, что в файле данных синтаксическая ошибка — браузер не
смог его прочитать и просто ничего не показал.

Как найти:

1. Открой страницу, нажми **F12** → вкладка **Console**.
2. Красная строка вида `Uncaught SyntaxError: ... posts.js:42` — число в конце
   это **номер строки** с ошибкой.

Три ошибки, из-за которых это случается почти всегда:

- **Забытая запятая** между записями или между абзацами.
- **Лишняя запятая** после последнего элемента списка.
- **Незакрытая кавычка** — в редакторе с подсветкой это видно сразу: весь текст
  после неё меняет цвет.

Пока не разобрался — верни файл в рабочее состояние:

```bash
git checkout assets/data/posts.js
```

Эта команда откатывает файл к последней запушенной версии. Всё, что не было
закоммичено, потеряется.

## 7. Правки оформления

Если правишь **`assets/css/*.css`** или **`assets/js/*.js`** — подними номер в
конце ссылок в HTML-файлах: было `?v=18`, стало `?v=19`. Это заставляет браузеры
посетителей забрать новую версию, а не показывать старую из кэша.

Заменить нужно во всех трёх файлах: `index.html`, `versions.html`, `blog.html`
(в `blog.html` свой отдельный счётчик).

**Для текстов записей и версий это не нужно** — данные обновляются и так.

## Где что лежит

```
index.html          главная страница мода
versions.html       архив версий
blog.html           блог (окна Windows 95)

assets/data/posts.js       ← записи блога
assets/data/versions.js    ← версии мода
assets/downloads/          ← сами jar-файлы

assets/css/style.css   оформление главной и версий
assets/css/blog.css    оформление блога
assets/js/main.js      логика главной и версий
assets/js/blog.js      логика блога (окна, гостевая, счётчик)
```
