Every version

Each build is pinned to the Minecraft and Fabric versions it was compiled against. Grab the one that matches your instance — a jar built for another Minecraft version will refuse to load rather than run badly.

    Notes on older builds

    • Legacy jars are kept exactly as they were published — they are not rebuilt or patched.
    • Every build targets one Minecraft version. Fabric Loader refuses to load a mismatch, so nothing breaks silently.
    • The mod is client-side and stores nothing, so downgrading is safe: no world data, no config, nothing to migrate.
    • Everything here is CC0-1.0 — do whatever you want with it, including the sources jars.
